# IntelliCourse AI

AI-powered university course discovery and learning path recommendation platform. Students describe their goals in natural language; the system returns semantically ranked courses, personalised to their history, with live market-trend context and progressive streaming results.

## Features

### AI-Powered Course Search
- **Hybrid retrieval** — BM25 keyword search runs in parallel with OpenAI semantic embedding search via `asyncio.gather()`; results are merged and re-ranked by a CrossEncoder (`ms-marco-MiniLM-L-6-v2`).
- **Streaming search (SSE)** — results appear progressively in four stages: keyword hits arrive in ~50 ms, final reranked list follows; no full-page wait.
- **WebSocket search** — bidirectional multi-turn chat-style search.
- **Query clarification** — short or ambiguous queries trigger a follow-up suggestion.
- **Filters** — difficulty level, minimum rating, required skills, top-K results.
- **Mock mode** — fully functional without an OpenAI key using BM25 + cosine similarity over in-memory data.

### Memory-Aware Personalisation
- Anonymous and authenticated user memory stored server-side per session.
- Frequency-weighted skill inference: skills from recent searches accumulate in a rolling window (`deque(maxlen=120)`).
- Post-hoc result re-ranking with an additive boost (capped at +0.25) favouring courses matching inferred interests.
- Full memory panel in the UI — view history, delete individual entries, or wipe the entire profile.

### Learning Path Generation
- Multi-step learning plans generated by GPT-4o for any career goal.
- Prerequisite mapping across courses with phased timeline.
- Export-ready structured JSON.

### Skill Gap Analysis
- Compare a student's current skills against a target role.
- Highlighted missing skills with course recommendations to close each gap.
- Readiness score per role.

### Career Path Intelligence
- Career-to-course alignment for 10+ roles.
- Salary estimates, demand level, and growth trajectory.
- Recommended skill order and learning timeline.

### FuturePath AI (Star Feature)
- **Multi-timeline simulation** — given a student profile, generates 3-4 possible future career paths with transparent probability scores.
- **Career Probability Engine** — weighted scoring formula across 6 dimensions:
  - Prerequisite coverage (25%), Skill match (20%), Learning capacity (15%), Difficulty alignment (15%), Career alignment (15%), Market demand (10%)
- **What-If Simulation Engine** — natural-language scenarios such as _"study 20 hours a week"_, _"skip mathematics"_, _"already know Python"_, _"choose GenAI Engineer"_; returns before/after comparison with delta probability, timeline change, and risk shift.
- **Learning Difficulty Simulator** — predicts Low / Medium / High difficulty risk based on career complexity vs weekly hours and preferred difficulty.
- **Timeline Type classification** — Conservative Path, Balanced Path, Aggressive Path, Experimental Path.
- **Course-grounded recommendations** — missing-skill courses sourced exclusively from the live indexed catalogue; no hallucinated course names.
- **Interactive React Flow career map** — step-by-step learning timeline with phase colour coding (Foundation → Core Skills → Advanced → Career Ready).
- **AI Mentor Explanation Panel** — mentor-style natural-language analysis with per-dimension score bars and weighted formula breakdown.
- **Probability / Radar charts** — Recharts bar chart (cross-path comparison) and radar chart (per-path score breakdown).
- **Simulation history** — last 20 simulations stored per user for replay and what-if derivation.
- **Mock-mode safe** — all scoring and generation is deterministic and dependency-free; no OpenAI key required.

### Market Trend Intelligence
- **Trending Skills Dashboard** — 20 skills ranked by demand score and year-over-year growth rate (e.g. Generative AI +340%, Prompt Engineering +450%, RAG +220%).
- **Career Demand Insights** — urgency level (Critical / High / Moderate), average salary, and top skills per career.
- **Emerging Technology Radar** — hype score, readiness level, and adoption timeline for 10 technologies (AI Agents, Multimodal AI, etc.).
- Live course-count cross-referencing against the ingested catalogue.
- GenAI spotlight surfacing LangChain, RAG, and Vector Database courses.

### Knowledge Graph
- In-memory directed graph built from courses at startup.
- Neo4j integration (optional) for persistent graph storage.
- 9 REST endpoints: graph overview, node/edge queries, topic clusters, related courses, learning path graph, skill co-occurrence, and graph rebuild.
- Interactive force-directed visualisation built with React Flow + Dagre layout.

### Interactive Learning Map
- Visual prerequisite map for any course or topic.
- Drag-and-drop React Flow canvas with zoom and pan.

### Notifications
- In-app notification system for saved-course alerts and recommendation events.

### Performance and Scalability
- **Dual-layer cache** — Redis (primary) with in-memory fallback. `mget`/pipeline batch reads, `scan_iter` pattern deletes (no blocking `KEYS`), hit/miss metrics.
- **Cache warming** — 6 popular queries pre-computed as a background task 5 s after startup.
- **Query embedding cache** — OpenAI embeddings cached in Redis for 24 h; never recomputed for repeated queries.
- **Batched embeddings** — all missing course embeddings computed in a single API call at ingest time.
- **Singleton CrossEncoder** — loaded once at first use via `asyncio.to_thread`; protected by `asyncio.Lock`.
- **Parallel search** — `asyncio.gather()` runs BM25 (CPU-bound, in `asyncio.to_thread`) and semantic search simultaneously.
- **Request timeout** — 15 s hard limit via `asyncio.wait_for`; returns HTTP 504 with a user-friendly message.
- **Single-pass filter** — one list comprehension with all conditions replaces five sequential passes.
- **Pagination** — all list endpoints support `page` / `page_size` with offset-based stable pagination.

### Search Pipeline

```
User query
    │
    ├── Redis embedding cache hit? ──yes──► cached vector
    │       no
    │       └──► OpenAI embed → cache 24 h in Redis
    │
    ├── asyncio.gather()
    │       ├── BM25  (asyncio.to_thread — CPU-bound)    ~10–50 ms
    │       └── ChromaDB semantic search (I/O-bound)     ~50–200 ms
    │
    ├── Merge + deduplicate
    │
    ├── CrossEncoder re-rank  (singleton, asyncio.to_thread)
    │
    ├── Memory personalisation  (+0.00–0.25 additive boost)
    │
    └── Cache result in Redis  (30 min TTL)
```

### SSE Streaming Pipeline

```
GET /api/stream/search?query=...
    │
    ├── event: start        (immediate)
    ├── event: bm25         (~50 ms)     → frontend renders keyword results
    ├── event: reranking    (~150 ms)    → UI shows "reranking" spinner
    ├── event: final        (~300 ms)    → replaced with reranked results
    └── event: done                     → stream closed
```

## Running Locally

### Prerequisites

- Python 3.11+
- Node.js 20+
- Redis (local or cloud)
- PostgreSQL 14+ (local or cloud — e.g. Neon)
- ChromaDB (local or cloud)

### Backend

```bash
cd intelli-course-ai/backend

python -m venv .venv
source .venv/bin/activate          # macOS/Linux
# .venv\Scripts\activate           # Windows

pip install -r requirements.txt

cp ../.env.example ../.env         # fill in credentials

uvicorn app.main:app --reload --port 8000
```

Interactive API docs: `http://localhost:8000/docs`

### Frontend

```bash
cd intelli-course-ai/frontend

npm install

echo "NEXT_PUBLIC_API_URL=http://localhost:8000" > .env.local

npm run dev
```

App: `http://localhost:3000`

## Agents

| Agent | Responsibility |
|---|---|
| `CourseRetrievalAgent` | Hybrid BM25 + semantic search, CrossEncoder re-rank, SSE streaming via `stream()` generator |
| `SkillGapAgent` | Role-to-skills mapping and gap analysis |
| `LearningPathAgent` | Phased roadmap generation via GPT-4o |
| `CareerAlignmentAgent` | Career-to-course alignment scoring |
| `AdvisorAgent` | Intent detection and agent orchestration |

## Quick Example Requests

```bash
# Streaming search (SSE — watch events appear)
curl -N "http://localhost:8000/api/stream/search?query=machine+learning+for+beginners&top_k=5"

# Blocking search
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{"query": "machine learning for beginners", "top_k": 5}'

# Learning path
curl -X POST http://localhost:8000/api/learning-path \
  -H "Content-Type: application/json" \
  -d '{"goal": "Become a Data Scientist", "current_level": "beginner"}'

# Skill gap
curl -X POST http://localhost:8000/api/skill-gap \
  -H "Content-Type: application/json" \
  -d '{"target_role": "ML Engineer", "current_skills": ["Python", "SQL"]}'

# Market trending skills
curl "http://localhost:8000/api/market/trending-skills?limit=10"

# Cache stats
curl "http://localhost:8000/api/cache/stats"
```
